📋 E n' G Bakery — Patch Notes v1.4

---

🛒 Orders
• Search Bar Enhancement — Searching for a product now automatically switches to the correct category, even if the product belongs to a different one.
• Distributed Status with Note — Orders can now be marked as "Distributed" with an optional note or dropdown.
• Food Panda Payment Restriction — For Food Panda orders, all payment amount options except "Exact" are now hidden. Only the exact amount is shown.
• Void Orders — Soft Delete — Voided orders are no longer permanently deleted. They are now soft-deleted and labeled as "Voided" in order history.
• Payment Methods as Buttons/Cards — Payment method selection has been redesigned from a dropdown/list into clickable button cards.
• Disabled Stock Items Hidden from Ordering — Products with disabled stock items in Inventory no longer appear as available options on the ordering page.
🗂️ Orders History
• Transaction History Format Applied — Order History now follows the same format as Transaction History. Default date range is set to 1 month.
• Food Panda Payment Label — Payment method for Food Panda orders is now correctly labeled as "Panda."
📦 Inventory
• Disabled During Add — Inventory is temporarily disabled while adding a new entry to prevent duplicate submissions.
• Add Notes — Users can now add notes when logging inventory entries.
• Stock Logic Fix — When a loaded distribution is deleted, stock is no longer refunded unless the entire distribution is deleted.
• Add/Minus Button for Distribution — Added increment and decrement controls for distribution quantities. A limit is displayed, but users can still exceed it — exceeding or falling short will require a note.
• Inventory History Detail View — Users can now view the full contents/details of a specific inventory entry from the Inventory History.
🧾 Material Stock & Costing
• Mobile UI Update — Improved mobile view for the Material Stock module.
• Search Bar Repositioned — Search bar in Material Costing has been moved to the right side.
• Unsync Quantity — Quantity in Material Costing and Material Stock are now independent of each other.
🛍️ Products
• Recommended Price Calculation Updated — Recommended Overall Price, Recommended Per Tray, and Recommended Per Piece now use a direct percentage multiplication method.
• Per Plate Removed — The "Per Plate" option has been removed from the product costing section.
• Selling Price Columns Added — Selling Price per Tray and Selling Price per Piece are now displayed in the product table, including on mobile view.
• Overhead Amount Added — An Overhead Amount field (Direct Cost + Additional Cost) has been added to the product costing breakdown.
• Bug Fix: Pieces/Trays Not Adjusting — Fixed a bug where going back to ingredients, adding or removing items, then proceeding to costing again caused pieces/trays values to not update correctly.
💰 Daily Remittance
• Editable Outlet Remittance — Daily Remittance Outlet fields are now editable.
• Food Panda Added — Food Panda has been added as a remittance category, placed between Cash Out and Online Payment.
💳 Transactions
• Panda Orders Included — Transaction history now includes Food Panda orders.
📊 Dashboard
• Order Number Format Updated — Order number display changed from ORD-20260225-001 format to 2026-03-07-1.
• Payment Method Update — Maya has been removed and replaced with Food Panda on the dashboard.
👥 Manage Employees
• Action Button Fix — Fixed broken action buttons in the Manage Employees section.
🔐 Login
• Auto Redirect on Session Timeout — Users are now automatically redirected to the login page when their session expires instead of staying on a frozen screen.
• Session Timeout Set to 60 Minutes — Login sessions now expire after 60 minutes of inactivity.
🔔 Notification System
• In-System Notifications — A notification system has been added across all modules.
🔧 All Modules
• Modal Click-Outside Disabled — Modals no longer close when clicking outside of them, preventing accidental dismissal.
