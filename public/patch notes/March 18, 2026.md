🟢 Patch Notes

1. Fix Group Label Overflow in Calendar — High Priority
   • Area: Distribution
   • Due: 03/18/2026
   • Summary: When the calendar displays distribution groups, labels that exceed more than two now show a condensed "+N" indicator (e.g., "+1", "+2") instead of overflowing. This keeps the calendar view clean and readable even when multiple groups are assigned to the same slot.
2. Add Manual Send Button for Inventory Report — High Priority
   • Area: Inventory
   • Summary: The previously scheduled auto-generated inventory report has been replaced with an on-demand approach. Instead of firing on a schedule, a Send Report button has been added so users can trigger the auto-generated inventory report manually whenever they're ready. This gives operators more control over when reports go out.
3. Sales Report Daily Line Graph — Low Priority
   • Area: Dashboard
   • Due: 03/18/2026
   • Summary: A new daily line graph has been added to the Sales Report section of the dashboard. This provides a visual day-by-day trend of sales data, making it easier to spot patterns, dips, or spikes in daily performance at a glance.
4. Fix Order Quantity Field Decimal Step — Low Priority
   • Area: Orders
   • Summary: The Order Quantity input field previously had an extremely granular step value of 0.0000001, allowing unnecessarily precise decimal entries. This has been corrected so the field now uses a sensible step value, preventing confusing micro-decimal inputs when placing orders.
5. Reformat Inventory Drinks Display — High Priority
   • Area: Inventory
   • Due: 03/19/2026
   • Summary: The Inventory Drinks section has been reformatted to follow the new layout as referenced in the pinned Messenger image. The display now shows three key columns: SRP (Suggested Retail Price), Qty Sold, and Sales — giving a cleaner, more actionable view of drink inventory performance.
